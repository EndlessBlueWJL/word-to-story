# 内容要求 · 最后确认版 v1

正文规则编号：`vocabulary-first-speaking-v1`；手机图片交付规则：`mobile-images-v1`。正文、词块和语法要求沿用最后确认版；本次新增全图片交付。后续修改应同步更新相关规范、示例、校验和对应版本。

## 目标与取词

1. 首要目标是每天背会35词；故事、对话和朗读都服务于词义与词块记忆。口语练习作为同一份材料上的第二目标。
2. 从用户提供的红宝书编号词表顺序取35词。保留原编号和拼写，不自行换词、选热点词或跳号。当前基准样例是332—366，同一批反复修改不算新进度。
3. 每个词至少在正文中出现一次原词形，便于精确核对；自然使用词义和搭配，不用单纯堆词、释义串或不合语境的句子凑覆盖。

## 文章与对话

- 每批1—4篇小故事或日常对话，覆盖全部35词。默认4篇，按语义分组，通常每篇8—10个目标词、80—110个英文词；不能为满足字数破坏自然度。
- 除目标词外，尽量全部用简单、常见、容易读出来的词。主动替换不必要的难词；避免同义词炫技、书面套话、复杂习语和额外学术词。
- 话题贴近雅思生活与社会话题，如学习、兴趣、社区、环境、文化旅行、工作和时间安排；内容用于练习，不是官方真题、评分保证或万能背诵答案。
- 适合一个人朗读和记忆：情节清楚、句子短、说话自然；对话可自己交替扮演双方。正式目标词也需要合理语境，不暗示每个词都适合所有日常回答。
- 句式联系考研常见语法，如定语从句、原因/条件状语从句、虚拟语气、非谓语等。每篇挑一个自然出现的结构，写简短说明；不强行堆长难句、倒装或多层从句。
- 中文仅给简短大意和当前语境中的词义，不用大段逐句翻译占满图片。

## 背词与开口任务

每篇必须包含：

1. 英文正文：目标词醒目高亮并附原编号。
2. 目标词栏：原编号、单词、本文用义、一个可背诵词块。词块必须含该词，且逐字出自这篇正文。
3. 一条句式提示：例句逐字出自正文，并简要解释语法和表达用途。
4. 简短复述线索，以及一个带空格的个人改写句。先读顺，再遮词回忆，看词块复述，最后换成自己的情况。

正文、遮词版本、35词打乱抽查和答案全部生成图片，学习者无需打开文件。抽查同时检查英文回忆、拼写和词块；不把“读顺了”当成“背会了”。Markdown、CSV、JSON和ZIP仅为后台工作与备份格式，默认不交付给学习者。

## 图片

- 1080×1920，竖版9:16。用户最初口语中的“竖着的16:9”已由后续样张明确为此方向。
- 一篇故事/对话及其词栏、语法和口头任务完整放在一张图。默认4篇就是4张，不拆成正文图、注释图。
- 正文42px/行距56px，目标词33px，中文词义与词块29px，保持大字易读。版面放不下就缩短内容或调整分组，不自动缩字号，不截断内容。
- 简洁米白底、清晰分区、少量颜色区分目标词。突出正文和背词，不增加装饰插图挤占字区。

## 手机端交付顺序

1. **① 朗读与背词**：每篇1张完整图，默认4张；含正文、词义词块、句式、复述与个人改写。
2. **② 遮词回忆与复述**：与正文逐篇对应，默认4张。完整遮词正文、原编号、中文提示和开口任务同张展示；不在题面露出英文答案。
3. **③ 35词打乱抽查**：全部题目先展示，看中文回忆英文、拼写和词块。题目分配到适合大字的独立题卡；按实际页数报告，当前35词示例为2张。
4. **④ 抽查答案与词块**：保持抽查顺序和题号，与题卡逐页对应；当前示例2张。所有答案卡放在所有题卡后面，不与题面混排。

默认示例共12张；不同词表按实际排版可能需要不同的抽查页数。读图清楚优先，不为了凑固定张数缩小字体。原故事/对话始终完整一张，增加练习图不是把原卡拆成两张。

每组开始用一行短说明写“下面N张是……，用于……”，再逐张嵌入图片。**每张图片前必须有一行独立可见的短编号/标题**（如“朗读1/4 · 博物馆”），空一行后嵌图，图后再空一行；不能只写图片alt文本。当前宿主会把连续的纯图片段落合并成并排缩略图，单有空行仍不够，需要真实文字分隔。图片内部包含组别、当前页/总页、词表范围或题号范围，即使保存到相册也能辨认顺序。

为手机竖屏设计：不使用多图拼成缩略图、并排网格、横向宽图或聊天内长表格。检查360px/390px宽度的模拟预览，并说明模拟不等于实机验证。优先使用宿主支持的直接图片预览，让用户点图即可放大；不得用ZIP、PDF、Markdown、CSV或仅服务器路径替代应展示的学习内容。备份只在用户索要时提供。

## 验收边界

程序检查：35词编号/覆盖、词块、语法例句、结构、图片尺寸、溢出、成品完整性及进度一致性。

Agent审读：其他词是否足够简单、语言与搭配是否自然、词义是否合适、话题和语法是否符合以上要求。程序不能仅靠规则可靠判定这些主观质量；必须保留人工复核的空间。
